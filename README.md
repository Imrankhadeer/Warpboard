# 🎧 WarpBoard

WarpBoard is a simple and customizable **desktop soundboard application** built with **Python**, using **Tkinter** and **ttkbootstrap** for a modern, responsive UI.  
It allows users to play and organize sound clips quickly through an easy-to-use interface.

---

## 🚀 Features

- 🎛️ Modern UI built with **ttkbootstrap**
- 🔊 Add, edit, and play sound buttons
- 🗂️ Customizable layout and themes
- 💾 Saves user configuration
- ⚡ Lightweight and responsive design

---

## 🧰 Tech Stack

- **Language:** Python  
- **UI Framework:** Tkinter, ttkbootstrap  
- **Tools:** VS Code  
- **OS Tested On:** Windows (Compatible with Linux)
